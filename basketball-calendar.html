Calendar Subscription

Subscribe to automatically receive calendar updates:

iOS (iPhone/iPad):

  1. Open Settings → Calendar → Accounts → Add Account → Other
  2. Select "Add Subscribed Calendar"
  3. Enter one of these URLs:
All Games:
webcal://molgar.github.io/Pruebas/calendars/basketball-all.ics

Mini Only:
webcal://molgar.github.io/Pruebas/calendars/basketball-mini.ics

Infantil Only:
webcal://molgar.github.io/Pruebas/calendars/basketball-infantil.ics

Cadete Only:
webcal://molgar.github.io/Pruebas/calendars/basketball-cadete.ics

Google Calendar:

  1. Open Google Calendar on desktop
  2. Click "+" next to "Other calendars" → "From URL"
  3. Paste the URL (replace "webcal://" with "https://")

Outlook:

  1. Open Outlook → Calendar
  2. Add calendar → Subscribe from web
  3. Paste the URL

Note: Subscribed calendars typically update every 24-48 hours. For immediate access, use the "Download" options above and import manually.
